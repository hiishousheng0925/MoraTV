# MoraTV 0.1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修掉 0.1.1 评估里的高 / 中级问题：漏匹配、擦边 / 动画混入、推荐质量、进度跨 key、演员搜索、题材筛选、显示名与布局。

**Architecture:** 在现有 SvelteKit 服务端（src/lib/server/search、cms、tmdb）和页面上改；不新增外部服务。

**Tech Stack:** 同 0.1.1（SvelteKit 2 / Svelte 5 / node:sqlite / opencc-js / hls.js / Electron）。

**Spec:** `docs/superpowers/specs/2026-10-22-moratv-design.md`（原设计）+ 两份评估报告（路径由主会话在派发时给出：eval-report.md = 0.1.0 评估 25 条；eval2-report.md = 0.1.1 复核 + 漏匹配体检）。评估报告是本计划的问题来源，条目编号以 eval2 为准。

## Global Constraints

- 界面简体中文；反馈只走 toast；不写教学式说明文字；不用原生弹窗。
- 仓库不得含个人信息（真名、公司邮箱、`C:\Users\<名字>`、Tailscale IP / 域名、上游网站 GitHub 账号）；API key 不进仓库，实测只用环境变量。
- 出站请求一律经 `net.js` 的 `fetchWithTimeout`；数据路径只走 `paths.js`；`+page.server.js` 只导出 SvelteKit 认可的名字；`$props()` 派生用 `$derived`。
- 测试 `MORA_HOME` 指向临时目录；只按 PID 结束进程（同机有其它 node / electron / python 常驻服务，用户自己的 MoraTV 装在别处并在运行，不得碰）。
- 动漫不在 MoraTV 范围内（交给 MoraAnime）：动画类目 / 动画 genre 一律不展示为可看作品。
- 擦边类目（福利、写真、两性、伦理、里番等）与「AI 漫剧 / 漫剧 / 动态漫」一律丢弃，任何页面都不出现。

## Review Focus

1. 合拍片 / TMDB 与资源站地区不一致（长城、偷天父子兵）→ 仍应匹配到正片，不再判无。
2. 同名动画版 / 同名不同作（苍兰诀动画、诺兰《奥德赛》vs 2025 英国恐怖片）→ 不得混进片源。
3. 没填 TMDB key 时看过的剧，填 key 后「继续观看」和续播位置不丢。
4. 资源站全部超时 → toast，推荐不出现整排灰卡，不写负缓存。
5. 擦边 / AI 漫剧类目在首页最近更新、搜索、浏览里都不出现。
